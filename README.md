# Marco Polo

Draw an area on the map. It finds the swimming pools in the aerial imagery, measures them and ranks them.

## What it does

It runs in the browser, with no server and no account. Imagery follows the place: DGT Ortos2025 in Portugal, PNOA in Spain, IGN in France, Esri World Imagery elsewhere.

Candidates come from colour; a small learned scorer (gradient boosted trees and an MLP, plain TypeScript, calibrated per source) rates each one. Every pool gets an outline, area, length, width and score. Export CSV or GeoJSON; the area lives in the URL.

## Run it

```bash
npm install
npm run dev       # localhost:5173
npm run verify    # every check, benchmark gate included
npm run scan -- --bbox "41.565,-8.385,41.574,-8.373"
```
