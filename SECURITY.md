# Security policy

Marco Polo is a web app that runs only in your browser, with no server and no user accounts.
To report a vulnerability, use [GitHub private vulnerability reporting](https://github.com/Sepd0x/marco-polo/security/advisories/new) for the Sepd0x/marco-polo repository, not a public issue.
Expect a reply within a week, and follow-up in the private advisory until the issue is closed.
